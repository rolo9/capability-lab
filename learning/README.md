## 実習の区切りで残すこと

- **入口**は手法名とよく使う別名。索引から事例へリンクする。
- **事例**には、何を知りたかったか、どんなデータで何を試したか、結果の図や数値、Notebookやコードへのリンクを残す。
- **振り返り**には、なぜその手法を選んだか、どんな条件で役立つか、学習者が言葉にした気づき、残った疑問を残す。実行結果と理解の記録は、それぞれ確認できた根拠を書く。

AIが実習の記録を整理して索引を更新する。実習を再開するときは、索引から以前の問いと結果を確認できる。
